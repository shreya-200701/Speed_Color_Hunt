# Speed Color Hunt 🎨🎮

An interactive real-time computer vision game built with **OpenCV** and **Pygame**. Players are challenged to find and hold up real-world physical objects matching target colors to score points before time runs out!

## Features
- 🎥 **Real-time Camera Feed:** Computer vision tracking using OpenCV HSV color masks.
- 🔊 **Synthesized Audio:** Custom sound effects generated on the fly with NumPy and Pygame.
- 🖼️ **Tkinter Integration:** Clean end-game summary window executed as a standalone popup process.
